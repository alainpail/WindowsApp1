# Projet_BTS_IHM_Banc_de _test_sofrel

IL s'agit du projet de fin d'année de BTS Système numérique informatique et réseaux.
dans lequel je devais concevoir une interface graphique utilisateur pour un banc de test de carte d'aquisition sofrel
je travaillé conjointement avec des collègues en BTS Système numèrique éléctronique et communication pour concevoir un protocole de communication entre l'ordinateur et le banc de test.
je récupéré les résultats du test avant de les afficher sur l'innterface.
